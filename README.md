# Google-Advanced-Data-Analytics-Capstone-Project

## Overview
This repository documents the completion of the **Cyclistic Case Study**, the final capstone project for the **Google Advanced Data Analytics Professional Certificate** offered through Coursera.

The goal of this project was to analyze historical bike-share data for "Cyclistic," a fictional bike-share company in Chicago. By following the **PACE (Plan, Analyze, Construct, Execute)** framework, I identified key usage patterns between casual riders and annual members to provide data-driven recommendations for converting casual riders into long-term subscribers.

## Technical Workflow
- **Plan:** Defined the business problem and established clear objectives for the data analysis.
- **Analyze:** Utilized **SQL** (BigQuery) to clean, filter, and aggregate millions of rows of trip data.
- **Construct:** Conducted Exploratory Data Analysis (EDA) and built interactive visualizations in **Tableau** to identify usage trends.
- **Execute:** Synthesized findings into a professional business report and presentation for stakeholders.

## Technical Proficiencies
- **SQL (BigQuery):** Data cleaning, multi-table joins, and complex aggregation.
- **Data Visualization:** Creating dynamic dashboards to display time-based trip trends.
- **Analytical Thinking:** Translating raw usage data into actionable marketing strategies.
- **Professional Communication:** Crafting clear narratives for executive-level stakeholders.

## Repository Structure
- `data/`                   # Raw and processed datasets
- `sql-queries/`            # SQL scripts for data cleaning and aggregation
- `tableau-dashboards/`     # Links/exports of final visualizations
- `analysis-report.pdf`     # Final business presentation and insights

## How to View
1. **Explore the SQL folder:** View the scripts used to process and clean the Cyclistic data.
2. **View the Tableau Visualizations:** Access the interactive dashboards to explore user behavior patterns.
3. **Review the Final Report:** Open the `analysis-report.pdf` to see the synthesis of the data and final recommendations.
